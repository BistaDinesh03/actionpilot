ActionPilot Playground

Local, deterministic adaptive-execution scenarios. No network, no AI, synthetic data only.

ScenarioWhat it proves
1 — Normal form completion observe → fill → submit → verify happy path
2 — Target changes stale target → fresh observation → deterministic re-target
3 — Verification delay action success vs. a distinct, bounded verification phase
4 — Bounded recovery failure → recovery decision → re-observe → re-target → success
5 — Approval runtime risk → existing approval gate (approve and deny)
6 — Terminal failure existing budgets stop an unrecoverable failure safely

Serve locally with python -m http.server 4174 --directory playground-site and open the local address it prints. Tests serve these files themselves on an ephemeral port. See docs/PLAYGROUND.md.
